# Requirements Archive: v1.6 Licensing

**Status:** ✅ SHIPPED 2026-06-17 — all 17 requirements complete/validated.

**Milestone goal:** One-time-payment lifetime license that unlocks full functionality — all 11 tools (including the Protobuf hero) stay free; Pro locks customization — theming and tool ordering/pinning (D-18); activation binds the key to one machine with self-serve transfer.

**Architecture (locked — `docs/licensing-research.md`):** Keygen perpetual + node-locked (`maxMachines=1`); unencrypted Ed25519-signed `machine.lic` verified in Rust (embedded public key + fingerprint `HMAC-SHA256(IOPlatformUUID, app-salt)`); license key in macOS Keychain (Rust-owned); React sees only `license_status`/`activate_license`/`refresh_license`/`deactivate_machine`; MoR checkout → webhook backend → Keygen license creation (privileged tokens server-side only); webview gating accepted as UX-gating, not DRM.

**Amendment (recorded in PROJECT.md):** "no network at runtime" gained a narrow licensing-only exception — one-time activation + opportunistic ~30-day TTL refresh; never per-launch checks; every tool remains fully functional offline.

## Requirements (all complete)

### Entitlements & Gating (ENT)
- [x] **ENT-01**: `ToolDefinition` supports `requiredEntitlements?: string[]`; tool gating derives from the registry.
- [x] **ENT-02**: An app-level entitlement map gates non-tool features: theming and tool ordering/pinning.
- [x] **ENT-03**: Entitlements resolve through one central gate; React receives only the resolved set (Rust command in Tauri; free-tier default in browser/test).
- [x] **ENT-04**: Free tier locks theming + ordering/pinning (all 11 tools stay free — D-18). Tool-gating mechanism ships dormant; locked features stay visible (WCAG-AA).
- [x] **ENT-05**: Registry tool entries load via lazy `component` loaders (future free-build decoder code-split seam; decoder.ts + its 19 tests untouched).

### License Lifecycle (LIC)
- [x] **LIC-01**: Paste a license key in-app to activate; one-time online step binds the key to this machine (HMAC fingerprint, Rust).
- [x] **LIC-02**: Activation enforces the seat limit server-side — a second Mac is rejected with a calm error naming the resolution.
- [x] **LIC-03**: After activation, every launch verifies fully offline (Rust Ed25519 verify of cached `machine.lic` + fingerprint, no network).
- [x] **LIC-04**: The license key lives only in the macOS Keychain (Rust-owned), used for refresh/deactivation — never readable from JS.
- [x] **LIC-05**: ~30-day TTL; opportunistic background refresh with generous offline grace — never a hard per-launch network check. _(Validated Phase 21.)_
- [x] **LIC-06**: A corrupt/tampered/foreign `machine.lic` fails closed to free — no crash, calm status, re-activation offered.
- [x] **LIC-07**: Self-serve deactivate this machine, freeing the seat to transfer to a new Mac. _(Validated Phase 21.)_
- [x] **LIC-08**: A revoked/suspended license propagates at the next TTL refresh — entitlements drop to free.
- [x] **LIC-09**: A license status UI shows the current state, masked key + licensee email, refresh + deactivate actions (WCAG-AA). _(Validated Phase 21.)_

### Purchase Pipeline (PAY)
- [x] **PAY-01**: Buy a lifetime license through a merchant-of-record checkout; in-app "Buy license" opens the purchase page.
- [x] **PAY-02**: A purchase-completed webhook creates the Keygen license (perpetual, node-locked, `maxMachines=1`); privileged tokens server-side only.
- [x] **PAY-03**: The buyer receives the license key by email automatically after purchase.

## Out of Scope (held)

- Subscriptions / recurring billing — one-time lifetime payment only.
- User accounts / cloud sync — the license key + machine file are the entire identity surface.
- Per-launch or per-call network checks — verification is local; network is activation + opportunistic TTL refresh only.
- DRM-grade protection — webview gates are patchable; accepted. No obfuscation.
- Rust rewrite of the decoder for protection — decoder.ts is immovable.
- Trials, coupons, regional pricing — MoR features usable later without app changes.

## Future (deferred — recorded, not promised)

- Multi-device tier (raise `maxMachines`); free-build decoder exclusion (ENT-05 seam); Windows/Linux licensing impl; Keygen production hosting decision; key→token exchange upgrade.
