## Milestone Summary

**Delivered:** the Mac App Store edition of TinkerDev, submitted for review at app version 1.0.0. One `package.json` script per channel builds either the direct Developer-ID DMG (unchanged) or the App-Sandboxed StoreKit `.pkg`. Both resolve Pro through the SAME central entitlement gate — the store build via `baseFromStoreKit` (on-device `currentEntitlements`, JWS-verified, fail-closed), the direct build via the unchanged Keygen `baseFromLicense`. The store build compiles out the entire Keygen/keyring/updater surface (sandbox-clean: app-sandbox + network.client only, no `keychain-access-groups`), and `decoder.ts` + its 19 tests are byte-for-byte untouched throughout.

**Key decisions:**
- In-store Pro = one StoreKit non-consumable IAP (`com.tinkerdev.app.pro`), perpetual, on-device JWS verify — serverless, no account/login. App Sandbox mandatory (`app-sandbox` + `network.client`). Updater + launch-at-login compiled out / hidden in the store build (SMAppService deferred to v2).
- Channel split is build-time: `--no-default-features --features appstore` drops the default `direct` umbrella feature; a `compile_error!` guard rejects a hybrid build. Capability overlays deliver channel-only permissions (`iap:*` for appstore, updater/autostart for direct) without breaking the other channel's codegen.
- Distribution `.pkg` ≠ launchable locally (AMFI -413): walkthroughs use the dev-signed `.app`; the distribution `.pkg` only runs after Apple re-signs at install.

**Issues / tech debt:**
- Two Transporter bounces on first upload — 409 (missing `LSApplicationCategoryType` → `bundle.category="DeveloperTools"`) and 91109 (`com.apple.quarantine` xattr on the embedded profile → `xattr -cr` before the seal) — both fixed permanently in `build-appstore-pkg.sh` with FATAL guards.
- Apple's review outcome is external and pending — not a GSD gap.
- Deferred (user-requested, post-submission): parallel builds via per-channel `CARGO_TARGET_DIR` so `build.sh` can fan out direct + appstore + pkg into independent artifacts.
- `gsd-tools` milestone/state/roadmap helpers mis-scope on this project's narrative format — milestone archival + tracking edits applied manually.
