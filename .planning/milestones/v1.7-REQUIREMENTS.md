# Requirements Archive: v1.7 Settings & Preferences

**Status:** ✅ SHIPPED 2026-06-21 (app v0.4.1) — all 10 requirements validated.

**Milestone goal:** A native macOS Settings/Preferences surface. **Architecture (locked):** a full in-window modal overlay (Claude-style) mounted shell-level via an `openSettings()` store (the Phase-21 upsell-modal pattern) — NOT a separate OS window. Native menu + tray entry points reach it through the `platform/` event seam. Promotes backlog 999.9; absorbs 999.3 theme settings + parked NAT-01/G-05-1 summon hotkey.

---

## Requirements (all validated)

### Surface & entry points
- [x] **SET-01**: Open Settings from the macOS app menu (TinkerDev ▸ Settings…, ⌘,) via the `platform/` event seam.
- [x] **SET-02**: Open Settings from the tray icon menu via the same event seam.
- [x] **SET-03**: Open Settings from a sidebar "Settings" row and the ⌘K command palette.
- [x] **SET-04**: Settings renders as a full in-window modal overlay, Esc-dismissible, WCAG-AA (focus trap + return-focus, `aria-modal`/`aria-labelledby`). **REVISED Phase 22.2:** reachable by everyone via sidebar row + Unlock-Pro footer + app-menu ⌘,/tray + `#/settings/license` deep link; the **⌘K palette is now Pro-gated** (a free user's ⌘K opens the focused Unlock-Pro modal).
- [x] **SET-05**: Paned layout (left nav, right content), fully keyboard-navigable (active pane announced via `aria`).

### Panes
- [x] **SET-06** (revised Phase 22.1): The **License** pane hosts `LicenseSettings` (all 5 states); the not-Pro states render the upsell/activation surface INLINE. **Scope grew:** the standalone `UpsellModal` was removed — exactly ONE upsell surface; every former opener routes to `openSettings("license", invoker)`. _(22.2 later re-introduced a thin focused modal over the SAME shared `ActivationSurface` for ⌘K/contextual triggers.)_
- [x] **SET-07**: The **Appearance** pane — theme (light/dark; "system" dropped 2026-06-17) + accent, persisted via the prefs seam, applied live whole-app, flash-free launch, Pro gate-on-Save (absorbs backlog 999.3). _(Validated Phase 23.)_
- [x] **SET-08**: The **Hotkeys** pane — view + rebind the global summon hotkey (Rust global-shortcut re-register + conflict handling, promotes NAT-01/G-05-1) and the ⌘K palette chord; both persist. _(Validated Phase 24; required granting `core:window:allow-show/set-focus/unminimize`.)_
- [x] **SET-09**: The **General** pane — launch-at-login (autostart plugin, the scoped dep exception), start-in-tray, default tool on open. (show-license-status-in-sidebar dropped at the walkthrough.) _(Validated Phase 24.)_
- [x] **SET-10**: The **Updates** pane — current version + last-checked + Check-for-updates (reuses the updater seam, mirrors the tray action) + **Install** (D-25-5 revised — second entry point to the shared install()). _(Validated Phase 25, 2026-06-21.)_
