  <action>
Create `src/shell/useAsyncFormat.ts` exporting `export function useAsyncFormat<O>(input: string, opts: O, runner: (input: string, opts: O) => Promise<FormatResult>): { result: FormatResult; pending: boolean }`.

Implementation (regex precedent, no worker):
- `const DEBOUNCE_MS = 180;` (150–200 window per D-02; comment the choice).
- `reqIdRef` monotonic counter, `debounceRef` timer ref.
- `useState<FormatResult>` seeded to the empty-ok state; `useState(false)` for pending.
- Effect keyed on `[input, opts, runner]` (opts by identity — callers memoize/pass primitives): clear the pending debounce timer; if `input.trim()===""` → `reqIdRef.current++`, set result to empty-ok, set pending false, return. Else `debounceRef = setTimeout(() => { const id = ++reqIdRef.current; setPending(true); runner(input, opts).then(r => { if (id !== reqIdRef.current) return; setPending(false); setResult(r); }).catch(() => { if (id !== reqIdRef.current) return; setPending(false); /* runner is total (error-as-value); catch is defence-in-depth */ }); }, DEBOUNCE_MS)`.
- Cleanup: clear `debounceRef`. Separate unmount effect bumps `reqIdRef` + clears timers.
- The latest-wins gate (`id !== reqIdRef.current`) protects ordering INDEPENDENTLY of the debounce (D-02) — a stale resolve is dropped even if debounce coalesced nothing.

Create `src/shell/useAsyncFormat.test.tsx` (`// @vitest-environment jsdom`, @testing-library/react `renderHook` + `act`, fake timers) covering every &lt;behavior&gt; bullet, especially the out-of-order-resolution stale-drop. Land GREEN with the impl.
