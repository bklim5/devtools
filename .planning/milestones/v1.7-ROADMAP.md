## Milestone Summary

**Delivered:** A complete five-pane Settings surface (License · Appearance · Hotkeys · General · Updates) as an in-window modal reachable from every entry point, with live theming, rebindable hotkeys (incl. the OS global summon), app-behavior toggles (incl. launch-at-login), and in-app update check + install. Registry stayed the single control plane; `SettingsModal` shell unchanged as panes were appended.

**Key decisions:** in-window modal overlay, NOT a separate OS window (one React root, shared prefs/entitlements/HashRouter); ⌘K palette gated behind Pro (22.2); "system" theme dropped; one autostart-plugin dep added as an explicit scoped exception to the zero-new-dep wedge; D-25-5 revised (Install in the Updates pane).

**Gates held across phases:** decoder.ts + its 19 tests byte-for-byte untouched; WCAG-AA (gsd-ui-review per phase); real-WKWebView e2e + human sign-off per phase; shipped as app v0.4.1 (notarized DMG).
