| Threat ID | Category | Component | Disposition | Mitigation Plan |

A `log stream sandboxd`-only check is insufficient (allowed outbound is not denied). A non-Apple host or unobservable traffic -> escalation, recorded in the walkthrough. |
| T-26-19 | Elevation | live grant on the signed build | mitigate | The walkthrough confirms the granted code is a real pro.* entitlement from a verified transaction (the Plan-01 fail-closed core runs on the live result); a grant without a verified transaction would be observed as a failure. |
