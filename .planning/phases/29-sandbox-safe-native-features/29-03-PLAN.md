## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| signed store bundle → macOS sandbox/AMFI/Gatekeeper | runtime-only failures (MissingEntitlement, AMFI-413, Keychain denial) surface ONLY on the signed sandboxed .app — invisible to unit/WebDriver gates |
| global hotkey + tray → window mutation | the summon/tray reveal mutates the window; under sandbox this needs the window-mutation capability to be granted (window-mutation-needs-capability) |
| tray menu → frontend updater seam | a tray "Check for Updates…" item drives the frontend updater.check(); the item + its frontend listener are gated out, but the runtime absence is only observable on the signed bundle with Console open |
