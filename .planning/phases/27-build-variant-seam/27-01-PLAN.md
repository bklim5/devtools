<objective>
Layer 1 of the build-variant seam: an umbrella `direct` Cargo feature (default-enabled) that carries the direct-only native deps — the auto-updater and the launch-at-login autostart plugin — so the appstore command (`--no-default-features --features appstore`) compiles them OUT entirely; PLUS the symmetric-inverse capability fix that keeps the appstore build's capability codegen GREEN once those plugins are absent.

Purpose: Cargo features are ADDITIVE — you cannot subtract a dep by adding a feature. The only way to drop updater + autostart from the appstore bundle is to move them behind a `default`-enabled feature and have the appstore build pass `--no-default-features`. This is the compile-out mechanism for MAS-BUILD-03 (Criterion 3); the direct DMG channel keeps both plugins exactly as today (D-05).

But there is a SECOND, blocking half (the symmetric inverse of the Phase-26 `iap:default` problem — 26-05-SUMMARY §80-84): Tauri's build-time capability codegen GLOBS + VALIDATES every file under `capabilities/` regardless of which Cargo features are active. `src-tauri/capabilities/default.json` STATICALLY grants `updater:default`, `process:allow-restart`, and `autostart:allow-enable/disable/is-enabled`. Once those three plugins are compiled OUT under `--no-default-features --features appstore`, the codegen fails the appstore build with `Permission updater:default not found` BEFORE any bundle is produced — exactly how a static `iap:default` broke the DIRECT build in Phase 26. The fix mirrors Phase 26 inverted: REMOVE the direct-only permissions from the static `default.json`, and re-deliver them to the DIRECT build via an inline `app.security.capabilities` overlay (`tauri.direct.conf.json`) that the appstore build never references.

Output: A gated `Cargo.toml` + `lib.rs` where `cargo tree --no-default-features --features appstore | grep -E 'updater|autostart'` is empty; a `default.json` stripped of the three plugin-bound permissions; a `tauri.direct.conf.json` re-granting them inline; and BOTH `cargo build` (direct, default) AND `cargo build --no-default-features --features appstore` compiling cleanly through capability codegen.
</objective>
