<objective>
Add the shared large-paste guard (SC6 / carried PRT-04) to the async formatting hook so a multi-MB paste can never enter the Prettier/esbuild main-thread engine path and freeze the UI, contradicting the <2s paste-instant promise.

This is the ONLY shared-file change in Phase 33. It lives in `useAsyncFormat` (D-03) as an optional `maxInputBytes` param defaulting to a shared 2 MB constant. Oversized input short-circuits to an `ok:false` `FormatResult` BEFORE the debounce/runner — mirroring the existing empty-input short-circuit. Phase 34 (JS/TS) inherits the guard verbatim (roadmap intent). The sync JSON/XML tools are deliberately NOT retrofitted this phase (deferred idea, not scope creep).

Purpose: close the Codex adversarial-review carry-forward (unbounded main-thread work) at the shared seam both Prettier tools consume.
Output: a guarded `useAsyncFormat` + its SC6 acceptance test proving 0 runner calls for over-cap input.
</objective>
