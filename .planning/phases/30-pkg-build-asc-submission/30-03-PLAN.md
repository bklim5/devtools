build-appstore-bundle.sh does: scrub APPLE_* notary env → build universal appstore bundle
  (`pnpm tauri build --features appstore --target universal-apple-darwin --bundles app
   --config src-tauri/tauri.appstore.conf.json -- --no-default-features`) → freshness guard
  (binary mtime > pre-build marker) → embed dev.provisionprofile → deep re-sign with the
  DEV identity + entitlements.appstore.plist → verify (lipo, codesign -dvvv, deep --strict)
  → verify-appstore-bundle.sh --require-bundle.

build-appstore-pkg.sh (NEW) makes EXACTLY these swaps + additions:
  1. SIGN_ID = `security find-identity -p codesigning -v | grep -oE '"Apple Distribution: [^"]+"' | head -1 | tr -d '"'`
     (NOT "Apple Development"). Fail closed if absent.
  2. PROFILE = src-tauri/embedded.provisionprofile  (the MAS distribution profile — "TinkerDev MAS",
     no ProvisionedDevices). Fail closed if absent → point at ASC-SETUP §7.
  3. INSTALLER_ID = `security find-identity -v -p basic | grep -oE '"3rd Party Mac Developer Installer: [^"]+"' | head -1 | tr -d '"'`
     (also try the modern label string for safety). Fail closed if absent → ASC-SETUP §7 (Pitfall 6).
  4. Inject `cp src-tauri/PrivacyInfo.xcprivacy "$APP/Contents/Resources/PrivacyInfo.xcprivacy"` +
     `chmod 644` BOTH the profile and PrivacyInfo BEFORE the deep re-sign (Pattern 2 — inject then seal).
  5. After the deep re-sign + the existing gates, ADD local pre-ITMS gates (D-02, no altool):
     - per-Mach-O sandbox-entitlement assert (ITMS-90296 / Pitfall 3): for every Mach-O under the .app,
       `codesign -d --entitlements - --xml` must contain app-sandbox; any miss → FATAL.
     - `chmod -R a+rX "$APP"` before productbuild + assert no root-only payload file (Pitfall 4).
     - `productbuild --component "$APP" /Applications --sign "$INSTALLER_ID" "$PKG_OUT"`.
     - `pkgutil --check-signature "$PKG_OUT"` shows a "3rd Party Mac Developer Installer" chain → else FATAL.
     - STRONG embedded-profile assert (Finding 3 — a stale/wrong/expired profile must fail HERE, not bounce at Transporter): decode the embedded profile with
       `security cms -D -i src-tauri/embedded.provisionprofile` piped to plutil/PlistBuddy and FATAL-assert ALL of:
         TeamIdentifier == `FK4HQK83WX`; application-identifier (Entitlements app id) == `FK4HQK83WX.com.tinkerdev.app`
         (consistent with entitlements.appstore.plist + tauri.conf.json bundle id); ExpirationDate is in the FUTURE;
         `get-task-allow` absent or false; and NO `ProvisionedDevices` key (a distribution, not dev, profile).
       Any mismatch → FATAL with an actionable message pointing at docs/appstore/ASC-SETUP.md §7.
  6. DO NOT notarise (scrub APPLE_* like the existing script). DO NOT gate on `spctl` accept —
     a MAS pkg legitimately rejects under Gatekeeper (not notarised); the runbook documents this (Pitfall 2).
  7. Re-assert freshness: the .app binary mtime must be > the last source commit (reuse the
     verify-appstore-bundle.sh assert_dist_freshness path via --require-bundle) — Build LAST (Pitfall 8).

productbuild command shape (30-RESEARCH Code Examples):
  xcrun productbuild --component "<App.app>" /Applications --sign "$INSTALLER_ID" "TinkerDev.pkg"

PKG output: gitignored (Plan 01 added *.pkg). Suggested path: src-tauri/target/universal-apple-darwin/release/bundle/macos/TinkerDev.pkg

| human action → Apple submission | Submit for Review is irreversible; gated behind the ship-gate walkthrough |
